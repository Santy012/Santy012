## Data & AI

| Project | Description | Stack |
| --- | --- | --- |
| [drone-detection](https://github.com/Santy012/drone-detection) | Real-time drone detection with YOLOv8n (mAP@0.5 99.4 %) and a serverless AWS backend. Two-person project with Camilo Millán; I planned, trained and evaluated the model. | Python, YOLOv8, ONNX, OpenCV |
